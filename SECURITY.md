# Security Policy / 安全策略

## Reporting a Vulnerability / 报告安全漏洞

If you discover a security vulnerability, **please do not open a public Issue**.

如果你发现了安全漏洞，**请不要公开提交 Issue**。

Report it privately via [GitHub Security Advisories](../../security/advisories/new).

请通过 [GitHub 安全通告](../../security/advisories/new) 私下报告。

I'll respond within **48 hours** and work with you on a fix.

我会在 **48 小时内** 回复并与你协作修复。

---

## Supported Versions / 支持的版本

Only the **latest release** receives security fixes. Please update to the latest version before reporting.

只有 **最新版本** 会收到安全修复。请在报告前先更新到最新版。

---

## Scope / 适用范围

| Concern / 问题类型 | Channel / 报告渠道 |
|-------------------|-------------------|
| Code execution, privilege escalation, data leaks / 代码执行、权限提升、数据泄露 | [Private vulnerability report](../../security/advisories/new) / 私下报告 |
| Crashes, UI bugs, feature requests / 崩溃、界面问题、功能建议 | [Public Issue](../../issues) / 公开 Issue |
