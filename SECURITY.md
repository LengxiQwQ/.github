# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, **please do not open a public Issue**.

Instead, report it privately:

- 🐛 [GitHub Security Advisories](https://github.com/LengxiQwQ/live-photo-box/security/advisories/new) (for live-photo-box)

I'll respond within 48 hours and work with you on a fix.

## Supported Versions

Only the latest release receives security fixes. Please update before reporting.

## Scope

| Concern | Channel |
|---------|---------|
| Code execution, privilege escalation, data leaks | Private vulnerability report |
| Crashes, UI bugs, feature requests | Public [Issue](https://github.com/LengxiQwQ/live-photo-box/issues) |
