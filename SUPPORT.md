# Getting Help / 获取帮助

## Need Help? / 需要帮助？

1. **📖 README** — Check the project README for documentation and usage guides. / 先查看项目 README 中的文档和使用说明。
2. **🔍 Existing Issues** — Search [open & closed Issues](../../issues?q=is%3Aissue) — your question may already be answered. / 搜索 [已有 Issues](../../issues?q=is%3Aissue)，你的问题可能已有答案。
3. **💬 Discussions** — Start a [Discussion](../../discussions) for questions and ideas. / 有疑问或想法可以去 [Discussions](../../discussions) 发起讨论。
4. **🐛 Bug / 💡 Feature** — Open an [Issue](../../issues) with the appropriate template. / 提交 Bug 或功能建议请用对应的 [Issue](../../issues) 模板。
