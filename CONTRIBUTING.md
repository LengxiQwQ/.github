# Contributing

Thanks for your interest in contributing!

## Bug Reports & Feature Requests

Open an [Issue](https://github.com/LengxiQwQ/live-photo-box/issues) with the template — detail helps a lot.

## Pull Requests

1. **Fork** → **Feature branch** (`feat/xxx` or `fix/xxx`)
2. **One PR = one thing**
3. **Match existing code style** — naming, formatting, comments
4. **Build and test** before submitting
5. **Clear PR description** — what & why

## Code Conventions

- Don't hardcode UI strings — use resource files
- Add file-level comments
- [Conventional Commits](https://www.conventionalcommits.org/) preferred

## Good First Issues

Look for `good first issue` or `help wanted` tags.
